Show one of the gateway's read-only runtime configuration views

Usage: fabric agent-gateway runtime show [OPTIONS] <VIEW>

Arguments:
  <VIEW>
          Possible values:
          - surface-routing: Surface routes, listen addresses and the OAuth callback route
          - x402:            x402 payment policy. The gateway answers 500, not 404, when it has no x402 configuration file
          - networking:      Inbound client-certificate (mTLS) authentication. Read-only: it is applied at startup and has no counterpart that sets it

Options:
  -c, --connection <CONNECTION>
          Named gateway connection. On `login` this names the connection being saved; on commands that talk to a gateway it selects which saved connection to use
          
          [env: FABRIC_CONNECTION=]

      --host <HOST>
          Override the configured gateway host for this command
          
          [env: FABRIC_HOST=]

      --token <TOKEN>
          Override the configured bearer token for this command
          
          [env: FABRIC_TOKEN]

      --allow-http
          Allow a plain http:// host that is not localhost. The session token is sent unencrypted, so only use this on a network you trust

  -o, --output <OUTPUT>
          Output format for commands that return data
          
          [default: table]
          [possible values: json, table]

  -h, --help
          Print help (see a summary with '-h')
