Create an Agent Surface using flags or a complete JSON document

Usage: fabric agent-gateway surfaces create [OPTIONS]

Options:
  -c, --connection <CONNECTION>
          Named gateway connection. On `login` this names the connection being saved; on commands that talk to a gateway it selects which saved connection to use [env: FABRIC_CONNECTION=]
      --name <NAME>
          
      --description <DESCRIPTION>
          [default: ""]
      --host <HOST>
          Override the configured gateway host for this command [env: FABRIC_HOST=]
  -f, --file <FILE>
          Complete AgentSurface JSON. Other creation flags are ignored when set
      --token <TOKEN>
          Override the configured bearer token for this command [env: FABRIC_TOKEN]
      --allow-http
          Allow a plain http:// host that is not localhost. The session token is sent unencrypted, so only use this on a network you trust
      --listen-address <LISTEN_ADDRESS>
          [default: 0.0.0.0:8080]
  -o, --output <OUTPUT>
          Output format for commands that return data [default: table] [possible values: json, table]
      --route <ROUTE>
          Inbound route. Defaults to a URL-safe form of the name
      --protocol <PROTOCOL>
          [default: a2a] [possible values: a2a, ap2, mcp, didcomm]
      --target-endpoint <TARGET_ENDPOINT>
          [default: http://127.0.0.1:3000]
      --tags <TAGS>
          
  -h, --help
          Print help
