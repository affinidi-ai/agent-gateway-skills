Create a secret using flags or a complete JSON document

Usage: fabric agent-gateway secrets create [OPTIONS]

Options:
  -c, --connection <CONNECTION>    Named gateway connection. On `login` this names the connection being saved; on commands that talk to a gateway it selects which saved connection to use [env: FABRIC_CONNECTION=]
      --name <NAME>                Human-readable name
      --host <HOST>                Override the configured gateway host for this command [env: FABRIC_HOST=]
      --secret-id <SECRET_ID>      Machine-readable identifier used by $SECRET:<secret-id> references
      --token <TOKEN>              Override the configured bearer token for this command [env: FABRIC_TOKEN]
      --value <VALUE>              Secret value, stored exactly as given including any whitespace
      --allow-http                 Allow a plain http:// host that is not localhost. The session token is sent unencrypted, so only use this on a network you trust
      --value-stdin                Read the secret value from standard input
      --description <DESCRIPTION>  What the secret is for
  -o, --output <OUTPUT>            Output format for commands that return data [default: table] [possible values: json, table]
      --reveal                     Print secret values instead of masking them
      --type <SECRET_TYPE>         Secret type, as configured on the gateway. Omit for the gateway default
      --tag <TAGS>                 Tag to attach. Repeat for multiple tags
  -f, --file <FILE>                Complete CreateSecretRequest JSON. Use '-' to read from standard input. Other creation flags are ignored when set
  -h, --help                       Print help
